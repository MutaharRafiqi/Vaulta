# Vaulta

> Your personal study vault.

Vaulta is a modern, minimal study management application that allows students to organize all of their learning resources in one place.

Instead of focusing on productivity or habit tracking, Vaulta is designed to become a centralized knowledge vault where users can store notes, formula sheets, books, question banks, and useful resources for every subject and chapter.

---

## ✨ Features (Version 1)

- 📚 Organize subjects
- ➕ Create unlimited custom chapters
- 📝 Store notes for every chapter
- 📐 Save formula sheets
- 📖 Store PDF books
- ❓ Maintain chapter-wise question banks
- 🔗 Save useful websites and links
- 🎨 Clean, modern and minimal interface
- 🌙 Dark mode design
- 💾 Local storage support
